# VK-бот «Кофе в удовольствие»

ВКонтакте-бот для магазина кофе в зернах. Показывает каталог сортов, прайс-лист, принимает заказы и отвечает на вопросы через AI.

## Что делает

- **Каталог** — 4 сорта кофе с описанием.
- **Прайс-лист** — цены по весам (250г / 500г / 1кг).
- **Оформление заказа** — сохранение в `requests.json`.
- **AI-ответы** — на свободные вопросы через ProxyAPI.

## Команды

- «привет» / `/start` — главное меню с кнопками.
- «каталог» — список сортов.
- «прайс-лист» — все цены.
- «оформить заказ» — приём заказа.
- «доставка» — информация о доставке.

## Сорта кофе

1. Бленд Бразилия х Эфиопия 50/50
2. Эфиопия Сидамо
3. Колумбия Супремо
4. Бразилия Можиана

## Установка

1. Создайте venv и установите зависимости:
   python3 -m venv venv
   source venv/bin/activate
   pip install vk_api openai

2. Скопируйте bot.example.py в bot_local.py и замените заглушки на свои ключи.
3. Запустите: python3 bot_local.py
